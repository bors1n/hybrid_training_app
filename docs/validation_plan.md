# План проверки спроса

Результат интервью 30.10.2026. Термины — в [GLOSSARY.md](../GLOSSARY.md). Этот документ не заменяет `hybrid_app_plan.md` (там продукт), а описывает запуск и проверку.

## Цель

Личный проект и проверка идеи; при успехе — заработок. Продукта в привычном смысле ещё нет: проверяются две гипотезы, и решение о платных продуктах принимается по итогам 90 дней, а не раньше. Платежи, лист ожидания и порог «готов заплатить» в проверку не входят.

## Гипотезы

- **H1 (тема).** Людям интересно не только качаться, но и бегать, делать комплексы. Проверяют медиа и подписчики.
- **H2 (инструмент).** Им нужен один журнал для силы и кардио, и они пользуются им, а не двумя приложениями. Проверяет приложение.

Позиционирование: журнал для тех, кто тренируется сам по информации из интернета; обещание — «можно отслеживать баланс тренировок». Планы с коучем и ИИ не конкурируем. Аналоги есть (см. [competitors.md](competitors.md)), поэтому в публичных текстах не писать «аналогов нет».

## Аудитория и канал

- Первый сегмент: люди, которые совмещают силу и бег и ищут один журнал вместо Hevy + Strava. Лозунг: «силу и кардио в одном журнале».
- Программа автора остаётся бесплатной и доступна по выбору.
- Единственный канал — органика нового аккаунта в Инстаграме (карусели, приглашение подписаться в каруселях). В России он работает через VPN; сайт и вход по почте остаются независимыми от него. Telegram не используется: нет органического трафика.
- Личный круг (80 человек) не приглашается и в пороги не входит. До старта приложение тестирует сам автор.

## Контент

- 5–8 часов в неделю на всё; до старта — одна карусель в неделю, статьи после появления рабочего приложения.
- Карусель №1 делается из темы недели (статья → карусель, на последнем слайде ссылка на статью и приложение). Карусель №2 отдельная: упражнение, комплекс, разбор тренировки; ссылка из неё ведёт на страницу комплекса или тренировки на сайте (только авторские #001…), там кнопка «Открыть в приложении» и инструкция «как поставить на iPhone».
- Из встроенного браузера Инстаграма PWA не установить, поэтому инструкция говорит «откройте ссылку в Safari». Отдельной метрики установки нет.

## Порядок работ

1. Деплой (этап 6): VPS, домен, HTTPS, почта с SPF/DKIM, PostgreSQL. Политика конфиденциальности, согласие на обработку e-mail (152-ФЗ), пометка «не медицинская рекомендация», в футере сайта `*` с подписью об Инстаграме (формулировку проверить у юриста).
2. Первый вход: выбор «свободный журнал» или «выбрать программу»; пометка «бета»; кнопка «Написать автору».
3. Картинка итогов тренировки (1080×1350, для сторис). Лент, друзей и рейтингов нет.
4. Страница HybridLog на сайте с кнопкой «Открыть приложение», инструкция «как поставить на iPhone» (три шага со скриншотами), аналитика; страницы комплексов.
5. Ведение аккаунта, карусели.
6. **День 1 проверки — день, когда опубликована первая карусель.** Если она выйдет раньше деплоя, это учитывается при чтении порога «открыли приложение».

## Измерение

- Пользователи и активные недели считаются по записям на сервере; трекеров в приложении нет.
- На сайте — лёгкая метрика без cookie (Яндекс.Метрика или Plausible).
- Главная воронка: карусель → страница на сайте → приложение.
- В бете первых пользователей спросить одним сообщением, что остановило бы от перехода с текущих приложений (если «история» — импорт Hevy/Strong идёт первым после проверки).

## Пороги за 90 дней

| Гипотеза | Показатель | Порог |
|---|---|---|
| H1 | Подписчики в Инстаграме | 300 |
| H2 | Открыли приложение | 50 |
| H2 | Ведут тренировки три недели и больше | 15 |

## Исходы

| H1 | H2 | Решение |
|---|---|---|
| есть | есть | Развиваем оба, определяем платный продукт |
| есть | нет | Медиа продолжаем, приложение остаётся личным журналом без развития |
| нет | есть | Редко; разбираем отдельно, возможно, приложение без медиа |
| нет | нет | Останавливаем, выводы по аудитории |

H2 «есть» — выполнены оба порога H2.

## Заморозка

До конца проверки новые функции не добавляются, кроме пунктов 2–4 и исправлений по обратной связи. Очередь, редактор программ и импорт Excel не развиваются и не показываются новичку на главной.

## Деньги

- Во время проверки платежей, оферты, самозанятости, листа ожидания и вопроса «готовы ли заплатить» нет. Заработок оценивается после 90 дней.
- Платным может быть только собственный контент автора: комплексы sportkuznica.com и набор RepDB не распространяются.
- Платные продукты не определены: доп. комплексы или отдельные программы; решать по итогам проверки.

## После проверки (кандидаты)

- Импорт из CSV Hevy и Strong — вероятно, самая сильная функция для первого сегмента; до старта не делаем.
- Платный набор: отдельная программа или набор новых комплексов, проверенных на безопасность нагрузок.
