# Уведомление в Роскомнадзор об обработке персональных данных (черновик)

Это заготовка для заполнения формы на портале персональных данных Роскомнадзора (pd.rkn.gov.ru, вход через Госуслуги). Перечень полей взят из образца уведомления, утверждённого приказом Роскомнадзора от 28.10.2022 № 180; перед подачей сверь поля с актуальной формой на портале и покажи юристу. Подаётся до того, как приложение откроется другим людям. Значения в `[[…]]` заполняет оператор.

| Поле формы | Что вписать |
|---|---|
| Оператор | [[ФИО]], физическое лицо (или ИП/самозанятый — как оформлен проект); ИНН [[ИНН]] |
| Адрес оператора | [[почтовый адрес]] |
| Контакты | почта [[почта для обращений]], телефон [[телефон]] |
| Цель обработки | Предоставление доступа к приложению HybridLog: вход по коду на почту, ведение аккаунта, хранение и синхронизация журнала тренировок пользователя, ответы на обращения |
| Правовое основание | Согласие субъекта персональных данных (п. 1 ч. 1 ст. 6 152-ФЗ) |
| Категории персональных данных | Адрес электронной почты; записи тренировок, заметки и настройки, внесённые пользователем; технические данные (IP-адрес, время запроса, тип браузера) |
| Специальные и биометрические категории | Нет. Сведения о состоянии здоровья оператор не запрашивает; пользователь вносит только записи о тренировках |
| Категории субъектов | Пользователи приложения HybridLog |
| Перечень действий | Сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, блокирование, удаление, уничтожение |
| Способ обработки | Смешанная: с использованием средств автоматизации |
| Передача третьим лицам | Почтовому сервису ([[Unisender Go или другой]]) для отправки писем с кодом входа, на основании поручения оператора |
| Трансграничная передача | Не осуществляется |
| Места хранения базы данных | Российская Федерация: сервер VPS у хостинг-провайдера reg.ru, адрес центра обработки данных [[из карточки услуги в reg.ru]] |
| Меры по обеспечению безопасности | HTTPS; коды входа хранятся в виде хэшей с ограниченным сроком; доступ к серверу по ключу SSH, межсетевой экран; ограничение числа попыток входа; резервные копии с ограниченным сроком хранения |
| Ответственный за обработку | [[ФИО ответственного]], [[почта]] |
| Дата начала обработки | [[дата открытия приложения]] |
| Срок или условие прекращения | Отзыв согласия пользователем или удаление аккаунта; иначе — прекращение работы приложения |

## Что подготовить к подаче

- [ ] Заполнить `OPERATOR` в `site/src/config.ts` (политика и согласие на сайте), собрать сайт: `deploy.sh` не пропустит сборку с незаполненными `[[…]]`.
- [ ] Подать уведомление и сохранить номер и дату.
- [ ] Убедиться, что политика (`/privacy/`) доступна на сайте и ссылка на неё есть на экране входа.
- [ ] Заключить или принять условия почтового сервиса и сверить, что он указан в уведомлении.
- [ ] Не открывать приложение людям, пока уведомление не подано.

Это заготовка, а не юридическая консультация. Особенно проверь: нужен ли оператору статус ИП или самозанятого для цели «проект», и корректно ли записи о тренировках не относятся к специальным категориям.
